# Organic Kit

Complemento de Blender (4.2 a 5.x) para crear **figuras orgánicas** —chibis anime, criaturas,
mascotas— con un clic o con código, y la base del agente «escultor orgánico» que trabaja en
Blender por MCP. Todo en modo Objeto, en milímetros.

- Chibi paramétrico por piezas de color (cuerpo, pelo, ojos) sin solapes, listo para imprimir en colores.
- Piezas de escultor por código: esqueleto con grosores, metabolas, tubos, mechones, ojos, orejas.
- Operaciones: fundir en un sólido, alisar sin encoger, engordar, simetría, booleanas, colores.
- Proyectos: alcance + cada pieza en su hilo, versiones por pieza y ensamblaje con STL por color.

Instalar: Editar → Preferencias → Complementos → Instalar desde disco → `organic_kit-1.0.0.zip`.
Guía completa en `organic_kit/LEEME.md`.
